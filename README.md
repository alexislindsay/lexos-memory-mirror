# LexOS Memory Mirror // ChatGPT Thought Archaeology

Turn raw, unreadable ChatGPT / Claude JSON export dumps into a fast, private, and interactive personal memory sanctuary.

## Features
- **100% Client-Side Privacy**: Runs completely in the browser via JavaScript. Zero telemetry, zero server storage.
- **Instant Search**: Full-text search across 400+ conversations and 10,000+ messages in under 5ms.
- **Topic Clustering**: Auto-sorts thoughts into Creative Novels, Coding, Philosophy & Mind, Italian Language & Sicily, and Career Strategy.
- **Export Studio**: One-click download of any conversation as formatted Markdown (`.md`) or copy to clipboard.
- **Curated Demo Mode**: Explore Alexis's thought archive out of the box with one click.
